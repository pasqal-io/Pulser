pulser.WeightedAnalogDevice

pulser.WeightedAnalogDevice = WeightedAnalogDevice

A realistic device for weighted-analog sequence execution.

Register parameters:

  • Dimensions: 2D

  • Maximum number of atoms: 256

  • Maximum distance from origin: 80 µm

  • Minimum distance between neighbouring atoms: 5 μm

Layout parameters:

  • Requires layout: Yes

  • Accepts new layout: Yes

  • Minimal number of traps: 150

  • Maximal number of traps: 512

  • Minimum layout filling fraction: 0.35

  • Maximum layout filling fraction: 0.5

Device parameters:

  • Rydberg level: 75

  • Ising interaction coefficient: 12241414.53

  • XY interaction coefficient: 48332.12053324995

  • Channels can be reused: No

  • Supported bases: ground-rydberg

  • Supported states: r, g

  • SLM Mask: Yes

  • Maximum sequence duration: 6000 ns

  • Maximum number of runs: 500

Channels:
  • ID: ‘rydberg_global’

    • Type: Rydberg (ground-rydberg basis)

    • Addressing: Global

    • Maximum \(\Omega\): 12.57 rad/µs

    • Maximum \(|\delta|\): 62.83 rad/µs

    • Minimum average amplitude: 1.8849555921538759 rad/µs

    • Clock period: 4 ns

    • Minimum instruction duration: 16 ns

  • ID: ‘dmm_0’

    • Type: DMM (ground-rydberg basis)

    • Addressing: Global

    • Maximum \(\Omega\): None

    • Bottom \(|\delta|\): -62.83 rad/µs

    • Minimum average amplitude: 0 rad/µs

    • Clock period: 4 ns

    • Minimum instruction duration: 16 ns
